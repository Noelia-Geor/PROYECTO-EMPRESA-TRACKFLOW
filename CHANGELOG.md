# Changelog

## [1.0.0] - 2026-09-12

### Añadido

- Webhook POST `/nutrition-check`.
- Validación del código de barras.
- Integración con Open Food Facts.
- Clasificación de azúcar, sal, grasa y Nutri-Score.
- Cálculo del veredicto final y concern score.
- Generación de consejos con IA mediante Groq.
- Rutas diferentes para saludable, moderado y no saludable.
- Manejo de errores y respuestas con datos insuficientes.
- Formato final de respuesta para el usuario.
- Documentación y registro de pruebas.
