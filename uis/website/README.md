# TrackFlow · Corporate website

TrackFlow's public website introduces its last-mile logistics and warehouse services, order journey, and locations in Los Angeles and Zaragoza.

## Stack

- Vite
- React and TypeScript
- Tailwind CSS 4 with `@tailwindcss/vite`
- Icons with `lucide-react`
- npm

## Run

From `uis/website`:

```bash
npm install
npm run dev
```

Validate or create a production build with:

```bash
npm run lint
npm run build
```
