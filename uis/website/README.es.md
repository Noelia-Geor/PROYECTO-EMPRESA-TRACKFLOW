# TrackFlow · Web corporativa

Sitio web público de TrackFlow, empresa de logística de última milla y gestión de almacenes. Presenta sus servicios, el recorrido de un pedido y sus ubicaciones en Los Ángeles y Zaragoza.

## Stack

- Vite
- React y TypeScript
- Tailwind CSS 4 con `@tailwindcss/vite`
- Iconos con `lucide-react`
- npm

## Ejecutar

Desde `uis/website`:

```bash
npm install
npm run dev
```

Para validar o generar la versión de producción:

```bash
npm run lint
npm run build
```
